\begin{rubric}{Research Interest}
\begin{minipage}{\linewidth}
{\large My research covers software engineering, machine learning, artificial intelligence, LLM agents, LLMs for code, and formal reasoning with the goal of modernizing and enhancing the reliability of large-scale software systems. To this end, I leverage program analysis and LLMs to automatically translate and validate repository-level code across different programming languages. So far, my work has focused on evaluating LLMs in code translation and investigating translation bugs~\cite{pan2024lost}, source code decomposition for code translation~\cite{ibrahimzada2024program}, and building end-to-end neuro-symbolic~\cite{ibrahimzada2025alphatrans} and agentic~\cite{ibrahimzada2026recodeagent} repository-level code translation and validation~\cite{ibrahimzada2026matchfixagent,ke2025advancing} tools. 
\\\\
Beside code translation, I have also enjoyed working on other problems in software engineering~\cite{ibrahimzada2025challenging,ibrahimzada2022perfect} and machine learning~\cite{ibrahimzada2026predicting,cakmak2023predicting,sohsah2020scalable}. }
\end{minipage}
\end{rubric}
